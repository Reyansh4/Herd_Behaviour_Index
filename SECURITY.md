# Report a vulnerability

If you believe you have found a security vulnerability in this project, please report it responsibly.

**Preferred:** Open a [private security advisory](https://github.com/your-org/your-repo/security/advisories/new) on GitHub (if the repository supports it).

**Alternatively:** Email the maintainers with a description of the issue and steps to reproduce. Do not open a public issue for security-sensitive findings.

We will acknowledge receipt and work with you to understand and address the issue.
